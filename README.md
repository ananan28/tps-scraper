# TPS 抓取器

## 功能
- 自动抓取 TruePeopleSearch 数据
- 姓名、年龄、居住地、电话
- 多并发浏览器
- 本地 SQLite 存储
- CSV 导出

## 部署步骤

### 1. 打包 EXE
```
双击 build.bat
```
等待完成，EXE 在 `dist/TPS抓取器.exe`

### 2. 复制到目标电脑
- 复制整个 `dist/TPS抓取器/` 文件夹到目标电脑（浏览器已内置，离线可用）
- 双击 `启动TPS.bat` 或 `TPS抓取器.exe` 运行

### 3. 配置
- **代理模板**: 你的代理用户名模板（带 `{session}` 自动换IP），如 `http://user-{session}:pass@host:port`
- **代理密码**: 你的代理密码（在界面填写，不内置）
- **CapSolver Key**: 你的 CapSolver API Key
- **并发数**: 32GB RAM 建议 15-20

### 4. 导入地址
- 粘贴地址列表（每行一个）
- 或从 TXT/CSV 文件导入

### 5. 开始抓取
- 点击"开始"
- 后台运行，可最小化

### 6. 导出数据
- 点击"导出 CSV"
- 数据保存在本地

## 消耗估算

### CapSolver
- 每次验证约 $0.003
- 1000 次验证约 $3
- 19 万地址约 $570（假设 100% 需要验证）

### niceproxy 流量
- 每个地址约 1-2MB
- 19 万地址约 200-400GB
- 按 $0.5/GB 算，约 $100-200

### 电费
- 每台电脑约 200W
- 20 台 × 24 小时 × 7 天 = 672 kWh
- 按 $0.1/kWh 算，约 $67/周

## 多电脑部署

### 方案
1. 打包 EXE 后复制到每台电脑
2. 每台电脑分配不同的地址段（避免重复）
3. 或者动态分配：做完一批领下一批

### 地址分配
- 19 万地址 ÷ 20 台 = 每台约 1 万地址
- 导出地址列表，分成 20 份

## 故障处理
- 浏览器崩溃：自动重启
- 网络断开：自动重试
- CapSolver 失败：自动重试 3 次
